# Oma Synergies Travels And Tours Ltd — Website

Official website for Oma Synergies Travels And Tours Ltd (omasynergiestravel.com) — global admissions processing, visa application support, study loan facilitation, and travel services.

## Tech Stack

- React 19 + TypeScript
- Vite
- React Router

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Status

- ✅ Home page — fully built, real content, all interactions (scroll reveals, animated counters, cursor parallax, FAQ accordion, rotating headline/subheading)
- 🚧 Remaining pages (About, Services, Destinations, Contact, Tours, Success Stories, Terms, Privacy) — exist as complete static HTML prototypes, being ported into React components next, following the same pattern used for the Home page
- 🚧 Client Portal — visual prototype complete, not yet connected to a backend
- 🚧 Admin Panel — visual prototype complete, not yet connected to a backend
- ⏳ Backend (Node/Express + PostgreSQL) — not yet started
